
# Orbit POS Marketing Website

Banking Without Boundaries. Deposits Without Limits.

The Orbit POS marketing website is a high-performance, flat-design platform built to represent the **Orbit 24/7 Network**. It serves as the primary touchpoint for agents, merchants, and enterprise clients looking to integrate with the most secure interbank cash-deposit gateway in the Kenyan market.

## Vision

To digitize the Kenyan economy by turning every street corner into a full-service bank branch through a secure, interoperable POS network powered by PesaLink.

## Design Philosophy

This site adheres to a **Strictly Flat & Minimal Fintech Aesthetic**:

- **Zero Gradients**: No glowing effects or color transitions in the UI components.
- **Zero Glassmorphism**: No frosted glass or transparency-based layering.
- **Solid HSL Palette**: Built on `--forest` (#0f3d1a) and `--accent` (#4ade80).
- **Clean Borders**: No hairline borders or subtle shadows; focus on bold, solid layouts.

## Site Structure

- **How it Works**: The 3-step process for hub-based banking.
- **Strategic Locations**: High-traffic hubs (Malls, Petrol Stations, SGR, Airports).
- **Orbit Agent Network**: Tiered agency models (Platinum, Gold, Silver) and multi-bank services.
- **Liquidity Ecosystem**: The 24/7 cash-and-float supply chain.
- **Sector Use Cases**: Tailored solutions for Restaurants, Healthcare, and Supermarkets.
- **Orbit Mtaani**: Neighbourhood-level banking points.

## Tech Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Vanilla CSS + Tailwind CSS (for layout only, avoiding utility-based "effects")
- **Animations**: Framer Motion (via `Reveal.tsx`)
- **Icons**: Lucide React

## Getting Started

1. **Install dependencies**:

   ```bash
   npm install
   ```
2. **Run the development server**:

   ```bash
   npm run dev
   ```
3. **Build for production**:

   ```bash
   npm run build
   ```

## Security & Compliance

All transactions represented on this site are powered by the **Orbit Middleware**, featuring:

- HMAC-signed PesaLink IPSL proxying.
- 24/7 remote terminal monitoring.
- Full CBK and AML/KYC regulation compliance.
